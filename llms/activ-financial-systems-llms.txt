# ACTIV Financial Systems

> Provider of real-time and historical financial market data, best known for the ACTIV Feed consolidated multi-asset feed and the OnePlatform. Acquired by Options Technology in 2021; market data capabilities are now delivered as part of the Options Atlas platform. The current public developer surface is the OnePlatform Web API (One API) — a WebSocket/WebAssembly JavaScript API for streaming, snapshot, query, and time-series market data.

Authentication is user/password credentials on session connect to a customer-provisioned OneApi Gateway; there is no self-serve sign-up, OAuth, or API-key scheme. The API is a session contract (connect → Session → snapshot/subscribe/query/timeSeries), not REST, so no OpenAPI is published; the machine-readable contract is the TypeDoc JSON shipped inside the @activfinancial/one-api npm package.

## Packages

- [@activfinancial/one-api](https://www.npmjs.com/package/@activfinancial/one-api): JavaScript/TypeScript API for the ACTIV OnePlatform (current generation)
- [@activfinancial/cg-api](https://www.npmjs.com/package/@activfinancial/cg-api): JavaScript/TypeScript API for the ACTIV ContentGateway (earlier generation)
- [npm @activfinancial scope](https://www.npmjs.com/search?q=activfinancial): 25 first-party packages including embeddable viewer web components
- [one-api-examples on GitHub](https://github.com/activfinancial/one-api-examples): open-source example applications
